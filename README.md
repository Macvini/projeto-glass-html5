# 🕶️ Projeto Google Glass — HTML5

Site informativo sobre o Google Glass, desenvolvido como projeto prático do curso de **Análise e Desenvolvimento de Sistemas**.

---

## 📋 Sobre o projeto

Site com múltiplas páginas apresentando o produto Google Glass, suas funcionalidades, especificações técnicas, galeria de fotos, multimídia e formulário de contato. Projeto focado na prática de HTML5 e CSS.

---

## 📄 Páginas

| Página | Descrição |
|---|---|
| `index.html` | Página inicial |
| `google-glass.html` | Sobre o Google Glass |
| `specs.html` | Especificações técnicas |
| `fotos.html` | Galeria de fotos |
| `multimidia.html` | Conteúdo multimídia |
| `fale-conosco.html` | Formulário de contato |
